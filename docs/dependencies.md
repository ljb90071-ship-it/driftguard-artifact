# Dependencies and attribution

The executable reference modules, tests, analysis, and HTML renderer use Python's standard library. No third-party source code or runtime package is vendored in this repository. No external dataset download is needed for the included examples.

The three PDF figures are companion figures from the manuscript. They use embedded DejaVu Sans fonts produced by the existing Matplotlib figure workflow; applicable font notices are included in [font-license.txt](font-license.txt). Matplotlib is not required to inspect these PDFs or run the supplied commands. This repository makes no claim to implement the native HIRE, XIndex, SALI, ALEX, or DILI engines; those names in the result archive identify comparison rows in the paper.
