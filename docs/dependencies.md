# Dependencies and attribution

The executable reference modules, tests, analysis, and HTML renderer use Python's standard library. No third-party source code or runtime package is vendored in this repository. No external dataset download is needed for the included examples.

Three PDF figures accompany the manuscript. Figures 1 and 3 are vector charts drawn from the residence replay and the two Figure 3 CSVs. Figure 2 combines raster storage illustrations with vector labels and paths. The DejaVu Sans fonts are embedded, with notices in [font-license.txt](font-license.txt). Opening the figures and running the reference checks require only a PDF reader and Python. The whole-system rows identify HIRE+, XIndex, SALI and the other comparison designs in the paper.
