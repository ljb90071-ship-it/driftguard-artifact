# Dependencies and attribution

The executable reference modules, tests, analysis, and HTML renderer use Python's standard library. No third-party source code or runtime package is vendored in this repository. No external dataset download is needed for the included examples.

The three vector figures accompany the manuscript. The plot inputs are the residence replay and the two Figure 3 CSVs. Their DejaVu Sans fonts are embedded, with notices in [font-license.txt](font-license.txt). Opening the figures and running the reference checks require only a PDF reader and Python. The whole-system rows identify HIRE+, XIndex, SALI and the other comparison designs in the paper.
